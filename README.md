I don't fix things. I find where they were never meant to hold.

I'm **V Vishwa Kumar**. I break things on purpose, document exactly why they broke, and tell the people who own them before anyone else does. Every system runs on unspoken promises — that this input is safe, that this boundary holds, that this user is who they claim to be. My work is proving when those promises are lies.

I don't chase bugs for their own sake. I go looking for the seam nobody patched because nobody knew it existed, then I stay until I understand why it was ever allowed to exist. Every engagement follows the same discipline: scope it, recon it, exploit it, gather evidence, disclose it, write down what it taught me. Half-documented findings are just anecdotes. If I can't reproduce it, it isn't a finding yet. I think in PoCs, not paragraphs.

Web applications, Linux internals, CTFs, bug bounties, DFIR — different playgrounds, same question every time: what did they assume nobody would try.

Right now I'm going deeper, past the vulnerabilities that already have names, into the ones still waiting to be found.

When I'm not breaking something on purpose, I'm building something quietly, so I know exactly how to take it apart later.
